# Grid: Power System Dispatch & Cost Evaluation Engine

This module contains the long-term (2020-2050) power system dispatch and multi-year planning evaluation engine for the **REX-Grid** framework. It receives the spatial renewable energy expansion decisions (from RL, Greedy, or LCOE baselines) and utilizes the Gurobi solver to optimize thermal power retirement, CCS retrofitting, energy storage deployment, and transmission network expansion.

## 📂 Architecture & Core Scripts

The execution flow relies on five core scripts:
* **`main_multiyear.py`**: The main controller. It iterates over different expansion modes (RL, Greedy, LCOE) and carbon scenarios (NDC, GM2.0, CN2050), advancing the simulation in 5-year steps from 2020 to 2050.
* **`dispatch_model.py`**: The mathematical core. Formulates the dual-layer investment and hourly dispatch optimization problem using `gurobipy`.
* **`typical_week_selector.py`**: A K-Medoids clustering module. It compresses the 8760-hour annual meteorological data into 7 representative days per month (2016 hours/year) to ensure computational tractability while preserving extreme weather events.
* **`utils_intra.py`**: Intra-provincial grid topology planner. Aggregates county-level renewable generation to city centers and estimates the required spur and trunk transmission investments.
* **`utils_yearly.py`**: The dynamic scenario loader. Maps and reads the distinct capacity expansion trajectories generated by different algorithms.

## 🗂️ Expansion Scenarios Directory Structure

The engine is designed to seamlessly evaluate different capacity expansion strategies. The function `load_decision_points_for_year` inside `utils_yearly.py` dynamically loads the regional wind/solar capacity data based on the current simulation year and expansion mode.

To run the model, you must organize your pre-calculated expansion result tables (`.xlsx`) exactly in the following directory structure:

```text
RL_main/
 └── expansion/
      ├── RL/                     # Results from the Reinforcement Learning agent
      │   ├── GD/                 # Guangdong province
      │   │   ├── expansion-RL_2025.xlsx
      │   │   ├── expansion-RL_2030.xlsx
      │   │   └── ...
      │   ├── GX/                 # Guangxi province
      │   └── HN/                 # Hainan province ...
      │
      ├── greedy/                 # Results from the Greedy heuristic baseline
      │   ├── GD/
      │   │   └── history/
      │   │       ├── expansion_greedy_2025.xlsx
      │   │       └── ...
      │   └── GX/ ...
      │
      └── LCOE/                   # Results from the LCOE-based baseline
